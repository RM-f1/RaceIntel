# Learnings

## FastF1 Session

The Session object contains race metadata, results, laps, telemetry, weather information, and timing data.

---

## Results

The Results object provides:

- Driver information
- Team information
- Grid position
- Finishing position
- Race status
- Championship points

---

## Laps

The Laps object contains:

- Lap times
- Sector times
- Tyre compounds
- Stints
- Pit stops
- Track status
- Tyre life

Accurate lap filtering is important before analysis.

---

## Telemetry

Telemetry includes:

- Speed
- RPM
- Gear
- Brake
- Throttle
- DRS
- Distance

Telemetry allows direct comparison of driver inputs over the fastest lap.

---

## Weather

Weather data contains:

- Air Temperature
- Track Temperature
- Humidity
- Wind Speed
- Wind Direction
- Rainfall

Weather provides context for interpreting race conditions but does not establish causation.
